# 定期連携のしかた

セッションをまたいで作業を続けるための手順です。前回の続きから、説明なしで動けるようにします。

## 1. 状況メモを出す
```bash
python status.py
```
相談したいことがあれば添えられます。
```bash
python status.py --note "Threadsのトークンを入れたい"
```

出てくるのはこんなメモです。そのままコピーして、セッションの最初に貼ってください。

```text
【買いまわり帳 定期連携 2026-09-16 08:10】

■ サイト
- 最終更新: 2026-09-16 05:30（毎朝5:30に自動更新）
- 公開URL: https://doramaru-gif.github.io/kaimawari/
- 今日のプラン: 10ショップ ¥10,000 / 見込み1,945pt（実質19.5%）
- 選定の記録: 3日分

■ Threads
- 接続: 未設定（アクセストークン待ち）
- キュー: 承認待ち0 / 予約済み0 / 投稿済み0 / 却下0 / 失敗0

■ 開催予定
- 2026年9月 お買い物マラソン 2026年9月19日（土）20:00 〜 9月24日（木）01:59（あと3日・上限7,000pt）

■ 相談したいこと
- Threadsのトークンを入れたい
```

## 2. 貼ったあとに伝えること
メモに出ない情報だけ、ひとことで足してください。
- うまくいかなかったこと（エラー画面はスクショで）
- 増やしたい機能、やめたいこと
- 期限（例：9/18の夜までに前夜告知を出したい）

## 3. こちらが毎回みるファイル
- `docs/PROGRESS.md` … これまでの決定と残りの作業
- `CLAUDE.md` … 規約上やらないこと、技術の前提、コマンド
- `docs/SETUP.md` … 設定の手順
- `logs/daily.log` / `logs/publish.log` … 自動実行の結果

## 4. 週に1回みるとよいもの
- 楽天アフィリエイトのレポート（クリック数・成果）
- Threads のインサイト（表示回数・返信数）
- Google Search Console（検索での表示回数）
- `python setup_check.py`（キーやタスクの状態）
