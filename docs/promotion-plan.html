2 / 相手と約束

誰に、何を約束するか

届けたい人お買い物マラソンに毎回参加する人です。開始直前から期間中に、スマホで「あと何ショップ」「1,000円ポッキリで何を買う」を探しています。
約束送料込み・1,000円台で、別々の10ショップを毎朝選び直す。買ったらスタンプが埋まり、本命の買い物を足したポイントは計算機で出せる。
届けるタイミング需要はマラソン期間に集中します。そのため投稿も、開始前夜から最終日に寄せます。期間外は検索と固定投稿に任せます。
Threads の投稿→プロフィールのリンク／リンクカード→買いまわり帳→楽天市場で購入（報酬）
Google 検索note 記事Pinterest→買いまわり帳

報酬は、買いまわり帳のリンクから楽天に入った買い物に付きます。どのチャネルも、最後はサイトに集めます。

3 / チャネル別の施策

どこで、どう届けるか

優先度の順に並べています。自動 は仕組みが動かすもの、承認 は承認デスクで押すだけのもの、あなた は手で行うものです。

Threads（最優先）

下書き・投稿は自動承認返信だけ
  • 1回のマラソンで7本出す：前夜・開始1時間前・開始直後・中日・ラクヨコ・最終日・残り2時間
  • リンク付きは3本だけ（開始直後・中日・ラクヨコ）。残りの4本は問いかけで終え、プロフィールのリンクへ誘導する
  • トピックタグは1投稿に1つ：「楽天お買い物マラソン」、ラクヨコの投稿は「楽天ラクヨコ」
  • 投稿後30〜45分に来た返信には、すぐ返す。ここだけはあなたの作業
  • プロフィールにサイトのURLを置き、使い方を説明する投稿を固定する（下のコピー素材を使う）

理由：Threads は「いいね」より返信（会話）を重く見て広げます。本文にリンクがある投稿は反応が30〜50%落ちるという報告もあります。

Google 検索（中長期）

毎朝の更新は自動登録だけ 10分
  • Search Console にサイトを登録し、sitemap.xml を送信する
  • ページは増やさない。同じ2ページを毎朝更新する（似たページの量産は、Google のスパム対策で落とされている）
  • 「毎朝の選定記録」は、ほかのサイトにない一次データ。マラソンの前後で合計がどう動くかを積み上げる

期待値：新しいサイトが検索で上がるには数か月かかります。マラソンは毎月あるので、同じページに何度も戻ってくる需要をじっくり取りにいきます。

note（記事1本）

最初に30分
  • 「1,000円台で10ショップ埋める組み方」を1本だけ書き、毎朝更新されるサイトへつなぐ
  • 冒頭とリンクのすぐ近くの両方に PR 表記を入れる（note の運用ルール）
  • 毎回書き直さない。数字はサイト側で毎朝更新されるので、記事は手順の説明にとどめる

Pinterest（任意）

1回5分
  • サイトが毎朝作るリンクカード用の画像（今日の合計とスタンプカード）を、マラソンごとに1枚ピンする
  • 自分で作った画像なので、楽天の商品画像を加工することにはならない。説明文に #PR を入れる

X（任意・低コスト）

必要なら
  • 出すのはリンクなしの投稿だけにする。API はリンク付きが1件 $0.20、リンクなしは $0.015
  • サイトへの誘導はプロフィールのリンクで行う
4 / やらないこと

規約と信用を守るために、やらないこと

  • ラクヨコの規約違反商品ページの自動取得や、商品画像・データの転載（利用規約 第13条）
  • リンクを送る場所LINE・Discord・DM・メールにアフィリエイトリンクを載せる
  • 楽天ROOMの自動化プログラムで投稿すること自体が ROOM の規約で禁止
  • 画像の流用楽天のページをスクリーンショットして使う
  • 自己購入自分や家族が、自分のリンクを経由して買う
  • 断定・誇大表現「絶対」「最安」など。承認デスクが自動で止める
  • リンクの貼り回りYahoo!知恵袋などへの書き込み。楽天アフィリエイトの認定SNSの外で、スパム扱いになる
